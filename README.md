# 네온 블라스터 ∞ TOUCH

예전에 제작한 네온 블라스터를 별도로 실행할 수 있도록 보관·배포하는 저장소입니다.

- 실행: GitHub Pages가 연결된 이 저장소의 공개 사이트에서 `게임 시작`을 누르세요.
- 원본: [충남 수호대에 보관된 네온 블라스터](https://github.com/piaroco12-web/chungnam-guardians/blob/main/legacy/neon-blaster.html)
- `index.html`은 원본 HTML의 내용을 수정하지 않고 파일 이름만 바꾼 것입니다.
- 게임 그림과 동작은 HTML 하나에 포함되어 있습니다. 한글 글꼴은 Google Fonts에서 불러옵니다.
- 충남 수호대는 [기존 사이트](https://piaroco12-web.github.io/chungnam-guardians/)에서 계속 실행할 수 있습니다.

배포: Settings → Pages → Deploy from a branch → main / (root).
